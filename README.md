## 🧠 Methodology

### Network Forensics
```
Wireshark → filter by protocol → export objects → VirusTotal/MalwareBazaar → any.run
```

### Malware Analysis
```
Static (strings, file type, hashes) → Dynamic (any.run sandbox) → IOC extraction
```

### Web Challenges
```
Enumeration → Source review → Identify vulnerability → Exploit → Document
```

## 📌 Writeup Format

Each writeup includes:

1. **Challenge Overview** — platform, category, difficulty  
2. **Tools Used** — specific to the challenge  
3. **Walkthrough** — step-by-step with screenshots/commands  
4. **Key Findings / Flags** — answers and IOCs  
5. **Lessons Learned** — what this challenge taught me  
6. **SOC Perspective** — how to detect and prevent this attack in a real environment
